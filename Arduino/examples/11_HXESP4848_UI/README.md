# HXESP4848 UI Demo

适用于 HXESP4848AI0210DIC-A（480×480、ST7701S、GT911）的 LVGL UI 示例。

- 启动页点击 `ENTER` 进入颜色测试。
- 颜色页支持 RED、GREEN、BLUE、BLACK、WHITE、GRAY；短按无动作，长按约 500 ms 进入全屏纯色显示，点击 `RESTORE` 返回。
- 左滑进入 TP 测试页，显示触摸状态、坐标、滑动、事件计数和当前触点数。
- 再次左滑进入 Wi-Fi、SD Card、BLE 的 UI 示例页；当前不执行实际硬件功能。
- 各页面可右滑返回上一页。

蜂鸣器临时测试已从本工程移除。
